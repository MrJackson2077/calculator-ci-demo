# Calculator CI/CD Demo

## Project Description

A simple calculator project that performs basic arithmetic operations (add, subtract, multiply, divide) and advanced operations (square, cube, square root).

## Technologies Used

- JavaScript

- NodeJS

- Jest

- ESLint

- Git

- GitHub

- GitHub Actions

- HTML

- CSS

## How to Run

### First Install All The Dependencies

npm install

### Run The Tests

npm test

### Run The Linter

npm run lint

### How To Run The Calculator

Open `index.html` in your browser. Or run `npm start`

### CI/CD Flow

- It is a CI/CD pipeline that runs on every push to the main branch.
- It runs the tests and the linter.
- If the tests and the linter pass, it builds the project.
- If the build is successful, it deploys the project.
